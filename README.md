# ENHANCED PULMONARY EMBOLISM DETECTION IN CT ANGIOGRAPHY

## Deep Learning based Pulmonary Embolism Detection using U-Net Architecture

## PROJECT OVERVIEW 

Pulmonary Embolism (PE) is a serious medical condition. This project focuses on detecting Pulmonary Embolism in CT Angiography images using image processing and deep learning techniques.

The project uses a U-Net architecture to generate segmentation masks and visualize the predicted regions.

## TECHNOLOGIES USED

  Python
  TensorFlow / Keras
  U-Net Architecture
  OpenCV
  NumPy
  Matplotlib
  Flask
  Tkinter
  
  ## PROJECT WORKFLOW

1. Load the CT Angiography image.
2. Preprocess the input image.
3. Resize and normalize the image.
4. Load the trained U-Net model.
5. Generate the predicted segmentation mask.
6. Visualize the output image with the predicted region.
